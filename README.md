속기사와 행정사가 함께 운영하는 **합동속기사** 타이틀의 심플한 원페이지 사이트입니다.

## 파일 구성

```
work3/
├─ index.html              메인 페이지 (전체 섹션)
├─ kakao.html              카카오톡 1:1 오픈채팅 페이지
├─ css/style.css           디자인 / 반응형
├─ js/script.js            메뉴 · FAQ · 카카오톡 링크
├─ images/hero-track.png   히어로 우측 사진 (러닝 트랙 · 레이싱화 끈)
└─ README.md
```

## ★ 카카오톡 오픈채팅 URL 연결 (요구사항 7)

카카오톡 오픈채팅방을 만든 뒤, 발급된 주소를 **`js/script.js` 맨 위 한 줄만** 바꾸면
`kakao.html`의 참여 버튼에 일괄 적용됩니다.

```js
// js/script.js  12번째 줄
const KAKAO_CHAT_URL = "https://open.kakao.com/o/실제주소를여기에";
```

> 현재 값은 `https://open.kakao.com/o/PLACEHOLDER` (자리표시자)입니다.

### 오픈채팅방 만드는 방법
1. 카카오톡 → **오픈채팅** → `+` → 채팅방 만들기
2. 공개 범위를 **비공개(초대장)** 로 설정 → 1:1 상담방 생성
3. 우상단 `…` → **공유** → 링크 복사 → `open.kakao.com/o/...` 주소 확인
4. 위 `KAKAO_CHAT_URL` 값에 붙여넣기

## 로컬에서 미리보기

